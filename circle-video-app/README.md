# Circle Video Share App

Приложение для обмена видео-кружками через GitHub.

## Возможности

- 🎬 Загрузка видео-кружков до 1 минуты
- 🔄 Показ случайного кружка (не вашего) после загрузки
- 👍 Лайки к кружкам
- 💬 Комментарии к кружкам
- ⚠️ Система жалоб (автоматическое удаление при 5+ жалобах)
- 🔧 Админ панель для управления кружками и просмотра жалоб
- ☁️ Все данные хранятся на GitHub через PAT ключ

## Настройка

### 1. Создайте репозиторий на GitHub

1. Создайте новый публичный или приватный репозиторий на GitHub
2. В репозитории создайте две папки: `videos/` и `data/`
3. В папке `data/` создайте пустой файл `circles.json` (можно просто `{}`)

### 2. Получите GitHub Personal Access Token (PAT)

1. Зайдите в GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Нажмите "Generate new token (classic)"
3. Дайте токену название (например, "Circle Video App")
4. Выберите права доступа:
   - ✅ `repo` (полный доступ к репозиториям)
5. Скопируйте токен (он покажется только один раз!)

### 3. Настройте .env файл

Откройте файл `.env` и заполните своими данными:

```env
PORT=3000
GITHUB_TOKEN=ваш_github_personal_access_token
GITHUB_OWNER=ваш_github_username
GITHUB_REPO=имя_репозитория
```

Пример:
```env
PORT=3000
GITHUB_TOKEN=ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
GITHUB_OWNER=ivanov
GITHUB_REPO=circle-videos
```

### 4. Установите зависимости

```bash
npm install
```

### 5. Запустите сервер

```bash
npm start
```

Сервер запустится на http://localhost:3000

## Использование

### Основной сайт (http://localhost:3000)

1. **Загрузить кружок**: Перетащите видео или выберите файл (до 1 минуты)
2. **После загрузки**: Автоматически покажется случайный кружок от другого пользователя
3. **Лайки**: Нажмите 👍 чтобы лайкнуть кружок
4. **Комментарии**: Добавьте комментарий к кружку
5. **Жалоба**: Нажмите ⚠️ чтобы пожаловаться на кружок

### Админ панель (http://localhost:3000/admin.html)

- Просмотр всех кружков
- Удаление кружков
- Просмотр всех жалоб
- Статистика по приложению

## Как это работает

Все данные хранятся на GitHub:
- **Видео**: Сохраняются в папке `videos/` как base64
- **Данные** (лайки, комментарии, жалобы): Сохраняются в `data/circles.json`

При загрузке кружка:
1. Видео конвертируется в base64 и загружается на GitHub
2. Информация о кружке добавляется в `circles.json`
3. Вам показывается случайный кружок (не ваш)

При достижении 5 жалоб:
1. Кружок автоматически удаляется из GitHub
2. Все связанные данные (комментарии, лайки, жалобы) удаляются
